# Czółko Online 🎭

Imprezowa gra w zgadywanie haseł (Who Am I?) po polsku. Bez moderatora i bez serwera – gra działa peer-to-peer (WebRTC / PeerJS), więc wystarczy GitHub Pages.

- Wszyscy widzą Twoje hasło – oprócz Ciebie.
- Zgadnij kim jesteś, potwierdź to z innymi graczami i zdobądź punkt.
- Gdy gospodarz pokoju wyjdzie, pokój automatycznie przejmuje kolejny gracz.

```bash
npm install
npm run dev
```
